## 存储与迁移

应用模型共 16 张表：`departments`、`roles`、`users`、`patients`、`allergies`、`audit_logs`、`temp_grant`、`passkeys`、`medical_order`、`consultation`、`consult_message`、`image_upload`、`health_plan`、`reminder_rule`、`reminder_log`、`call_log`。连同 `alembic_version`，建库脚本要求 17 张表与两个审计触发器。

merge revision `f18a03c94b62` 汇合 main 审计与旧分支业务表两条迁移；head 为 `a9c327e80f16`。空库、main 旧 head、旧问诊 head 均应升级到同一 head，不重写既有 revision。

`passkeys` 为旧兼容表；目前不代表有 Passkey 登录能力。`call_log` 只存已结束通话元数据，没有录像文件。图片与数据库分别备份，不能只备份镜像。

## 路由与前端

本分支运行时 OpenAPI 有 42 个 HTTP 路径，另有一个 `/ws/chat/{room_id}` WebSocket 路由。契约是目标全集，不能用契约路径总数代表交付数量。

M3：`/api/consultations`、`/{id}`、`/{id}/accept`、`/{id}/end`、`/{id}/messages`、`/records`、`/export`、`/{id}/calls`，以及 `/api/uploads/images`、`/uploads/{filename}`、`/ws/chat/{room_id}`。records/export 静态路径必须在 `/{id}` 前注册。

`ConsultationsView`、`ConsultationRecordsView`、健康方案/提醒、患者、审计页面接真实业务 API。Dashboard、MedicalRecord、HealthManagement、ReviewQueue、RemoteConsultation 仍含演示数据引用，不属于本次 M3 全面收口。UI 英文；文档中文。Token 沿用 main 的 localStorage，AGENTS 已同步实际行为；双人测试请使用独立浏览器配置文件。

## 复核方法

在 backend 执行 `uv run pytest -q`、`uv run alembic heads`、`uv run alembic check`；在 frontend 执行 `npm test`、`npm run build`。模型表集合可用 `from app.main import app; from app.models import Base` 后读取 `Base.metadata.tables`。测试和真实媒体验收边界记录在 M3 工作记录中，未验证项目不标已完成。
